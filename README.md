# 4×5 脱出パズル

目標駒を盤面下中央の出口へ導く、ブラウザ向けのスライディングブロックパズルです。スマートフォンとPCの両方で動作し、タッチ、マウス、ペン、キーボードから操作できます。

本作は独立制作の非公式なスライドパズルです。特定の製品・企業との提携・承認関係はありません。公開物には、公式ロゴ、商品写真、説明書、固有の追加配置、既成の解答データを含めていません。

## 主な機能

- 4列×5行の盤面と、下辺中央からの明示的な脱出操作
- Pointer Eventsによるドラッグと衝突位置でのクランプ／スナップ
- タップ＋方向ボタン、最遠移動、キーボード操作
- Undo、Redo、Restart、手数、アクティブ時のみ進むタイマー
- LocalStorageによる進行状況とベスト記録の復元
- Web Worker上のBFSソルバーによる、現在局面からのヒントと解答再生
- レスポンシブ表示、ライト／ダーク配色、Reduced Motion対応

## ローカルで起動

リポジトリの親ディレクトリでHTTPサーバーを起動します。

```sh
python3 -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000/sliding-block-puzzle/
```

このディレクトリ自体をカレントディレクトリとしてサーバーを起動した場合は、`http://localhost:8000/` で開けます。ES ModulesとWeb Workerを使用するため、`index.html` のファイル直開きではなくHTTP経由で確認してください。

## テスト

外部パッケージのインストールは不要です。Node.js 20以降を使用してください。

```sh
npm test
```

盤面バリデーション、合法／不正移動、履歴、保存データの拒否、状態正規化、およびソルバーが返すすべての手を適用して脱出できることをテストします。

## キーボード操作

- `Tab`: 駒やボタンへフォーカス
- `Enter` / `Space`: 駒を選択
- 矢印キー: 選択した駒を1セル移動
- `Shift`＋矢印キー: 選択した駒をその方向の最遠位置へ移動
- `Ctrl/Cmd`＋`Z`: Undo
- `Ctrl/Cmd`＋`Shift`＋`Z` または `Ctrl/Cmd`＋`Y`: Redo
- `R`: リスタート確認
- `H`: 次の一手を探索
- `Escape`: 選択解除またはダイアログを閉じる

## 実装上の方針

盤面状態と移動検証はDOMから分離しています。ソルバーは固定解答を持たず、同形駒を位置順に正規化した状態空間をBFSで探索します。解答手は駒種と座標で実際の駒へ対応付けるため、同形駒のID交換に依存しません。

タイマーはページが表示中で、1手以上進み、未クリアの場合だけ加算します。解答再生による移動も通常の履歴と手数へ加えられ、Undoできます。

## 既知の制約

- 問題は独自に定義したクラシック配置の1問です。
- 問題生成、共有URL、Service WorkerはMVP外の任意拡張として未実装です。
- LocalStorageを無効化している環境では自動保存されませんが、ゲーム自体はプレイできます。
